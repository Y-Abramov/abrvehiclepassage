# ABR | CIVIL - Проезд ТС

Прогоняет расчётное транспортное средство (в том числе автопоезд) по указанной
линии и строит в чертеже заметаемые коридоры следа колёс и габарита кузова,
отпечатки, оси, отметки нарушений и штамп с расчётными величинами.

## Поддерживаемые версии Civil 3D

| Civil 3D | Серия |
|---|---|
| 2024 | R24.3 |
| 2026 | R25.1 |

## Команды

| Команда | Действие |
|---------|----------|
| `PASSAGE` | Построить проезд через диалог |
| `PASSAGEUPDATE` | Пересчитать проезд (без выбора - все проезды чертежа) |
| `PASSAGEERASE` | Удалить проезд: графику и запись в чертеже |
| `PASSAGELIB` | Редактор библиотеки машин |
| `PASSAGESETTINGS` | Настройки по умолчанию |
| `PASSAGEABOUT` | О модуле |

## Как задать путь

`PASSAGE` принимает полилинию, отрезок, дугу, сплайн, характерную линию Civil 3D
или трассу Civil 3D. Для трассы можно указать диапазон пикетов - тогда проезд
строится только на этом участке. Излом полилинии по умолчанию сглаживается дугой
минимального радиуса выбранной машины; отключить сглаживание можно в диалоге -
тогда излом отрабатывается как разворот на месте и помечается нарушением.

## Откуда берутся габариты машин

Встроенный набор расчётных ТС взят из действующих нормативов (СП 396.1325800.2018,
ГОСТ 33062-2014, СП 4.13130.2013 - для пожарной техники, Постановление Правительства
РФ № 2200 - предельные габариты автопоездов). Источник конкретного норматива и пункта
показан в карточке машины и попадает в штамп чертежа.

## Как добавить свою машину

`PASSAGELIB` открывает редактор библиотеки. Встроенные машины недоступны для прямой
правки - кнопка «Создать копию» делает из встроенной пользовательскую, которую можно
менять. Пользовательский набор хранится в `%AppData%\Abr\Civil\vehicles.json` и
переживает переустановку модуля. Экспорт и импорт файлом - для передачи набора
коллеге.

## Известные ограничения этапа 1

- Путь задаётся только полилинией/трассой; интерактивное вождение - этап 2.
- Проверка зазоров между коридором и объектами чертежа - этап 2.
- Задний ход не поддерживается.
- Текстовый вывод - только штамп в чертеже, экспорт в XLSX не предусмотрен.
